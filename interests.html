Одоогоор ажиллаж буй төсөл: Smart Study Planner App

Би одоогоор оюутнуудад зориулсан хичээл төлөвлөлтийн аппликейшн хөгжүүлж байгаа бөгөөд энэ нь миний программ хангамж хөгжүүлэлтийн практик мэдлэгийг маш ихээр нэмэгдүүлж байна.

Аппликейшний гол боломжууд (Features):

  • Хичээлийн хуваарь болон суралцах цагийн төлөвлөлт
  • Даалгавар удирдах хэсэг (Task management, deadline, priority)
  • Сануулга өгөх болон даалгаврыг хойшлуулах (Postpone, repeat task)
  • Долоо хоногийн тайлан ба гүйцэтгэлийн явцыг хянах (Weekly report, progress tracking, chart)

Ашиглаж буй технологиуд:

  1. HTML, CSS, TypeScript (Frontend)
  2. Vite (Build tool)
  3. Node.js (Backend)
  4. Firebase (Database & Auth)
  5. Git / GitHub (Version Control)
