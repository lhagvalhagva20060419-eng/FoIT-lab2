Миний тухай товчхон

Сайн байна уу? Намайг О. Лхагва гэдэг. Би Программ хангамжийн инженерчлэл (Software Engineering) чиглэлээр суралцдаг 2-р курсын оюутан. Миний гол зорилго бол их сургуулиа амжилттай төгсөөд олон улсын түвшинд ажиллах чадвартай, өндөр бүтээмжтэй software engineer болох юм.

Одоогоор Java Backend Development, систем хөгжүүлэлт, өгөгдлийн сан болон компьютерын сүлжээний чиглэлээр түлхүү төвлөрөн суралцаж байна.

Боловсрол & Академик амжилт

Монгол Улсын Их Сургууль (МУИС) — Мэдээллийн технологи, программ хангамжийн инженерийн бакалаврын хөтөлбөр (2-р курс):

  • Сурлагын голч дүн (GPA): Ойролцоогоор 3.9
  • Суурь хичээлүүд дээр А, А+ үнэлгээтэй суралцаж байгаа

Одоогоор гүнзгийрүүлэн судалж буй их сургуулийн хичээлүүд:

  1. Объект хандлагат программчлал (Object-Oriented Programming)
  2. Өгөгдлийн сангийн систем (Database Systems)
  3. Өгөгдлийн бүтэц (Data Structures)
  4. Компьютерын сүлжээ (Computer Networks)
  5. Компьютерын системийн зарчим 1 (Computer System Principles 1)
  6. Интернэт технологийн үндэс (Fundamentals of Internet Technology)

Мэргэжлийн ур чадвар

Хичээл болон бие даасан төслүүдийнхээ хүрээнд эзэмшиж буй гол ур чадварууд:

  • Java: OOP зарчмууд (Inheritance, Polymorphism, Encapsulation), Collections Framework, JUnit 5 тестинг, Exception handling
  • Бусад хэл: C++ (Алгоритм, бодлого бодох), Python (скрипт ба жижиг төсөл), JavaScript
  • Вэб хөгжүүлэлт: HTML5, CSS3, Modern JavaScript, Vite, REST API-ийн үндэс
  • Инфраструктур & Хэрэгслүүд: Linux (Ubuntu, WSL2), Docker (Containers, Images, Volumes), Git/GitHub
  • Computer Science: Data Structures, Algorithms, Problem Solving

Суралцах зорилго & Алсын хараа

Миний алсын хараа бол технологийг ашиглан бодит асуудлыг шийдвэрлэх чадвартай, тасралтгүй суралцдаг, найдвартай систем бүтээдэг инженер болох юм.

  1. Ойрын зорилго: Java Backend чиглэлээр Spring Boot, REST API, Database-ийг гүнзгийрүүлэн сурч, практик төсөл дээр ажиллах
  2. Дунд хугацааны зорилго: Мэргэжлийн түвшний дадлага (internship) хийж, бодит бизнесийн систем хөгжүүлэлтэд оролцох
  3. Хэтийн зорилго: Гадаадад магистрт (Master's Degree) 100% тэтгэлэгтэйгээр суралцаж, олон улсын түвшний Software Engineer болох

Дэлгэрэнгүй төлөвлөгөө, хичээлийн хуваарийг Миний төлөвлөгөө хуудаснаас үзнэ үү.
